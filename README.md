# Personal GitHub Pages Site

This is a static one-page personal website designed for GitHub Pages.

## What to customize

- The current copy is filled from your OpenMentor and Carrd pages.
- Booking links currently point to your sessions page and Google booking form.
- The blog section currently points to LinkedIn because no public Substack URL was found in the provided pages.
- Update the role, bio, booking tiers, case studies, and links directly in `index.html`.

## Publish on GitHub Pages

1. Create a repository named `yourusername.github.io`.
2. Add these files to the repository root.
3. Push to the `main` branch.
4. In GitHub, open Settings, then Pages, and make sure it publishes from the `main` branch root.

The site entry point is `index.html`.
